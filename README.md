## The rant

> The self-checkout screamed 'UNEXPECTED ITEM IN THE BAGGING AREA' at the carrots I had just scanned myself, in front of a queue now convinced I'm a carrot thief. I didn't steal anything. I just wanted carrots. Now a cashier watches me like I'm smuggling produce, and I have trust issues with a machine that can't count to one.

## Why it's funny

The machine publicly accuses an innocent shopper of the pettiest crime imaginable — stealing carrots — and the rant escalates that false accusation into a full reputation crisis: a queue of witnesses, a suspicious cashier, and lasting trust issues with a machine that cannot even count to one. The anger is real, the crime is absurd, and the punchline lands on the machine's incompetence rather than the shopper's.

## Run it

```sh
node main.ts
```

This writes the rant to `/output/entry.txt`, validating first that it is 1–400 characters and not only whitespace, then reading the file back and failing unless it is byte-identical to the rant.
